## Selected Projects

### FecaiCTI NEXUS

A modular cyber threat intelligence and external attack surface monitoring platform for organizations.

It focuses on leaked credentials, threat detections, alerts, incidents, fake domains, dark web signals, vendor risk, VIP protection, compliance, and operational security workflows.

### Null Linux

An Arch-based cybersecurity Linux distribution designed for security research, privacy, and offensive/defensive workflows.

It provides curated tooling for red team, blue team, OSINT, OPSEC, forensics, networking, web security, wireless security, and exploitation.

### CyberRSS

A self-hosted intelligence feed aggregator for cybersecurity, AI, and technology content.

It is designed to collect, normalize, classify, and present relevant technical content from multiple sources in a clean and useful format.

### Broowser

A Firefox-based browser project focused on privacy, security, and a cleaner browsing experience.

It explores hardened defaults, browser customization, privacy tooling, and user-friendly security improvements.
